# Third-party resources

This directory incorporates and adapts public resources from:

- Repository: https://github.com/flaqai/backlink_skills
- Upstream license: `UPSTREAM-LICENSE`
- Imported resource snapshot: `backlink-candidates.md`
- Adapted submission controls: the V2 quality references, record template and audit script

The upstream project is used as a planning and execution-SOP reference, not as a guarantee that any listed website is available, free, relevant, accepting submissions or valuable for SEO. Recheck every route before any later use.

The local `growth-acquisition-execution` skill adds the project-specific boundary: it only qualifies resources, prepares plans and handoffs, and defines how external listing work must connect to qualified acquisition, referral visits, activation and revenue evidence before it is treated as growth impact. It does not perform live external actions.
